The full contributing guide is kept with the project's GitHub files, so it's always the version that applies to every repository:

**[Read the contributing guide](https://github.com/redeclipse/.github/blob/master/CONTRIBUTING)**

It covers where to get help, what each repository holds, reporting issues, suggesting features and content, pull requests, licensing, commit messages, AI-assisted contributions and the [code of conduct](https://github.com/redeclipse/.github/blob/master/CODE_OF_CONDUCT).

## Quick Links

* Get the source with `git clone --recurse-submodules https://github.com/redeclipse/base.git redeclipse`, then follow [Building from Source](Install-Guide#building-from-source).
* Report a bug or request a feature on the [issue tracker](https://github.com/redeclipse/base/issues/new/choose).
* Ask for help in the [help and support discussions](https://github.com/redeclipse/base/discussions/categories/help-and-support) or on [Discord](/discord).
